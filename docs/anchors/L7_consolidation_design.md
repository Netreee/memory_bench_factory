# L7_consolidation 设计(剩余三线第三条)—— 长跨度趋势归纳,按"被坑 5 波后"的纪律生

> **坐标**:`L7_consolidation / 巩固摘要 / 长跨度要点·趋势回忆(非逐字)`。**状态**:v0 已建(S1+S2,自检 20/20),待 e2e+盲审。
> **★v0 范围决策**:只做 **S1 趋势 + S2 对比**(gold 是标量/名字,接地判分脆度低)。**S3 阶段对比 deferred 到 v1**——它的 gold 是【字段名集合】,集合型接地/判分易引入歧义,本着"源头做对、不贪多、不造软 gold"暂不做。
> **一句话**:答案不是某周的某个值,是**把散落全程的事实整合成一个方向/对比判断**;且**最近一期会误导你**(抗 recency、抗逐字)。
> ★把 `pitfalls_4lines.md` 的账前置成出生约束(§0)。L7 的命脉 = §6 的**趋势分类器 + margin 必须实测定标**(直接复用 L4 众数-margin 那套,否则就是批量造 ill-posed)。

## 0. 出生即带的纪律(抄血泪,逐条说清 L7 会在哪复发)
1. **gold 出厂即唯一人类口径**:L7 答案 = 趋势标签(`上升/下降/波动`,**固定枚举**)/ 实体名(对比题)/ 字段名集合(阶段对比)。**全是人类口径类别/名字,答案侧无 session/周号**——和 L4 一样,L7 天然规避 TR 那个裸-session 坑。实体名走 `_strip_disambig` 规范(复用 L2/L4)。
2. **完成判据 = 下一波独立盲审**。L7 盲审命门:① reader 整合全程能得到该趋势;② **答最近一期 = 错**(签名);③ 代码标签 ≈ 人类标签(分类器没把"波动"叫成"上升")。
3. **★闸条上线前必过真实数据 FP/覆盖**:趋势天生"软"——`[1,3,2,4]` 算升还是波动?**TREND_MARGIN / 对比 MARGIN 必须拿真实序列定标**(代码标签 vs 人类标签的分歧率),分歧太高 = 这型是症状代理,**像 W5/roles_of 一样毙掉**。
4. **无补丁**:趋势判定走结构化分类器(数升降次数 / 净变号),**不准**"题面含'趋势'就…"之类。
5. **type-critical 表面不交给 LLM**:趋势词是**固定 enum**(上升/下降/波动),疑问词/选项模板锁死,不准 LLM 自创趋势词(坑#6)。
6. **源头做对、闸只兜底**:enumerate 只在"有明确趋势/明确赢家"时产单。

## 1. 能力定义(和 L1.MR / L3 / L4 不重叠在哪)
**L7 = 长跨度趋势/对比的格式塔判断。签名 = 必须整合全程,且最近一期误导。**
- vs **MR**(数值聚合 sum/avg/极值):MR 是"把这摞收据加总=多少钱"(算术、单值);**L7 是"看完这摞收据,这店生意变好还变差"**(方向、非数)。
- vs **L3**(事件排序):L3 问"按先后排好";L7 问"整段的走向/谁变得最多",**不要顺序,要格式塔**。
- vs **L4**(类别众数):L4 = 散落选择的众数(类别);L7 趋势 = 数值序列的方向。正交。

**三型(全部 code-falsifiable + 带 margin):**
| 型 | 题面 | gold | 确定性命门 |
|---|---|---|---|
| **S1 趋势方向** | "综合全程,X 的 P0 整体趋势?" | `上升/下降/波动` | `sign(净变化)` ∧ `\|升次−降次\| ≥ TREND_MARGIN`;不够→波动或跳 |
| **S2 跨实体对比** | "全程哪个部门负责人变动最频繁?" | 实体名 | `argmax_e changes(e)` ∧ 冠亚军差 ≥ MARGIN(防平手) |
| **S3 阶段对比** | "前 k 周 vs 后 m 周,X 主要变了哪些?" | 字段名集合 | 两窗口 `value_at` 不等的字段集(非空、非全) |

## 2. 世界基质(prepare —— L7 也几乎不造新世界,挑"够长够动"的字段)
L7 **不引入新字段类型**,只挑现有世界里"跨度够长、变动够多"的序列:
- S1:某数值字段 ≥ T_MIN 个不同 session 有值,且**有明确单调倾向**(否则是波动/跳);
- S2:≥2 实体在某关系/字段上变更次数**拉得开**(冠亚军差 ≥ MARGIN);
- S3:存在能切两窗、且窗间有差异的实体。
- prepare 轻;真正的活在 §6 的"够不够明确"判定。

## 3. feasible / enumerate / gt(命门2)
- **feasible**:∃ 满足 §1 命门的 (实体,字段)/实体对/可切窗实体。不满足→跳。
- **enumerate**:每个合格机会产 1 单。
- **gt(护城河,代码复算)**:
  - S1:`gt = trend_label(seq)`,`seq = [value_at_session(s) for s in 有值周]`,分类器见 §6;
  - S2:`gt = argmax 实体名`(changes 用现成 `gt_event_order` 计数,单一真源);
  - S3:`gt = {窗1≠窗2 的字段名集}`。
  - `gt()` 重算 == 烘焙 → 校验闸。

## 4. intent(题面)—— 强制"看整段" + 不给 anti-recency 提示(考的就是它会不会被最近一期骗)
```
S1: f"综合【{ent}】全程「{fld}」的变化,整体趋势是?{interrogative('trend')}"   # 给固定选项:上升/下降/波动
    "——看整段走向,别只看最近一期。"
S2: f"全程来看,哪个{entity_noun}的「{fld}」变动最频繁?{interrogative('person')}"
S3: f"对比【前 {k} 周】与【后 {m} 周】,{ent} 主要在哪些方面变了?"
hide = [str(gt)]    # 只藏结论;每期具体值【留在语料】(边B证据,reader 要靠它整合)
```
- ★**绝不在题面泄漏趋势/最近值导向**;`trend` 疑问词 = 固定枚举提示(分类题,给候选)。

## 5. ★消费者路径审查(逐字段问"会被读错吗")
| shipped 字段 | 人类消费者读它会怎样 | 判 |
|---|---|---|
| `gt`(S1 趋势标签 / S2 实体名 / S3 字段名集) | 直接当答案,人类口径类别/名字 | ✓ 无歧义 |
| `aux.up/down/margin`(S1)、`aux.counts`(S2) | **计数,非周号**(不会被格式化成"第N周") | ✓ |
| `aux.window=(k,m)`(S3) | 周数窗口;若进题面→过 `week_label` 1-based | ⚠ 题面用 1-based |
| `evidence_sessions` | 0-based 内部,脱敏剥;**L7 答案侧无周号**(答的是趋势/名字/字段) | ✓ 天然规避 TR 坑 |
> 结论:L7 人类口径答案 = 趋势标签 / 实体名 / 字段集,**设计上就没有"周/裸值"可被误读**(和 L4 同源思路:出生就不给消费者挑错的机会)。

## 6. ★边A 良定义(命脉:趋势分类器 + margin 必须实测定标)+ 边B 接地
**S1 趋势分类器(确定性,gold 唯一真源):**
```
ups   = #{i: seq[i] > seq[i-1]};  downs = #{i: seq[i] < seq[i-1]}
if ups - downs >=  TREND_MARGIN: 上升
elif downs - ups >= TREND_MARGIN: 下降
else: 波动     # ← 模棱两可的归"波动";若"波动"难接地/难判,enumerate 阶段直接跳(不产)
```
**边A(well_posed,每条实测定标后才留——坑#3/#4):**
- **WP1(S1 趋势明确)**:`|ups−downs| ≥ TREND_MARGIN`。★**TREND_MARGIN 必须拿真实序列量"代码标签 vs 人类标签分歧率"定标**——这是 L7 的边A∩边C 核心,等同 L4 的众数 margin。分歧高 = 这型不可靠,毙。
- **WP2(S1 抗 recency)**:**最近一期不得单独泄漏趋势**(如升势但末点下挫;否则"答最新"也能蒙对 → 退化成 KU,drop 或标 trivial)。这是签名,必须强制。
- **WP3(S2 无平手)**:冠亚军变更数差 ≥ MARGIN(并列→drop)。
- **WP4(S3 差异集非平凡)**:窗间差异字段集非空、非"全变"(全变=信息量 0)。
- **WP5**:gold==复算(护城河)。
- **不设**"序列长度/方差"等看着像、未实测的代理。

**边B 接地**:确立趋势/对比所需的**每期值须散落在 ≥ T_MIN 个 session** 的文档里(证据够散,reader 才能整合);不足→弃。普通"值在场"接地 + **查 spread**。

## 8. 自检用例(necessary-not-sufficient;fixture 用真实 schema 词表,防假绿坑#6)
